<h2>Objetivos</h2>
<p>Reunir os códigos fontes do TDE da disciplina de Programação Back-End, que irá compor 20% da nota da primeira avaliação do<br>semestre letivo atual, os fontes são baseados em material disponibilizado pelos professores da disciplina.</p>

<h2>Padrões de projeto</h2>
<p>Todos os atributos privados das classes, são iniciados com um <b>underline</b> na nomenclatura.<br>Exemplo:</p>

```
private int _modelo;
```
<p>Todas as classes possuem uma classe main respectiva, que é nomeada de acordo com o <i>nome original da classe + Main</i>.<br>Exemplo:</p>

```
ContaBancaria.java 
MainContaBancaria.java
```
